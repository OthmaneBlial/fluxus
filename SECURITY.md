# Security policy

## Supported code

There is currently no verified npm release of `@othmaneblial/fluxus`. Security fixes target the `main` branch and, once releases exist, any version explicitly named as supported in the current release notes. The unrelated unscoped `fluxus` package is outside this project's scope. The workbench is a local in-memory demo and does not provide authentication or remote storage.

## Report a vulnerability privately

Use [GitHub's private vulnerability report form](https://github.com/OthmaneBlial/fluxus/security/advisories/new). Private vulnerability reporting was enabled for this repository on 19 September 2026. Include the affected commit or package version, a minimal reproduction, impact, and a way to discuss a fix. Do not put credentials, private user data or exploit details in a public issue or pull request.

The maintainer will triage the report, reproduce it, coordinate a fix and publication when appropriate, and credit the reporter if they wish. No response or fix deadline is promised. If the private report form is unavailable, use the contact method on the [maintainer's public GitHub profile](https://github.com/OthmaneBlial) to ask for a private channel without sharing exploit details in that first message.
