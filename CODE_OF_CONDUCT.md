# Code of conduct

Fluxus discussions should be useful and safe for people with different experience levels. Be specific and respectful when reviewing code, asking for help or disagreeing with a design decision. Critique behavior and evidence rather than a person's identity or competence.

Harassment, threats, personal attacks, hate speech, sexualized attention, doxxing and repeated disruptive behavior are not acceptable in repository discussions, issues or pull requests. Do not post someone else's private information without permission.

If a discussion becomes unproductive, the maintainer may ask for changes, hide or remove content, lock a thread, or restrict participation. Decisions will be based on the behavior and context; this project does not promise a fixed response time.

For a conduct concern, contact the maintainer through the contact method on the [public GitHub profile](https://github.com/OthmaneBlial). Share only what is needed to explain the concern, and do not put sensitive personal details in a public issue. Security vulnerabilities use the separate [private security channel](SECURITY.md).
